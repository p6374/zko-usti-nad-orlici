Otevřít administraci

Editor Pages CMS ukládá změny přímo do propojeného GitHub repozitáře. Web je následně automaticky nasazen přes Cloudflare Pages.

↗ Otevřít editor webu
Editor vyžaduje přihlášení k účtu GitHub, který má přístup k webu. Heslo se na této stránce nezadává.

Jak přidat člena a psa

  1. Přihlas se přes GitHub.Při prvním spuštění může být potřeba povolit Pages CMS přístup k repozitáři.
  2. Otevři repozitář p6374/zko-usti-nad-orlici.Vyber větev main a položku „Členové a psi“.
  3. Otevři „Seznam členů ZKO“.Člena lze přidat do seznamu, pod jeho jménem přidat psa a vyplnit zkoušky.
  4. Vyber fotografii a ulož.Fotografii můžeš vybrat z galerie telefonu. Změny se nejprve uloží na GitHub a po nasazení se ukáží na webu.
